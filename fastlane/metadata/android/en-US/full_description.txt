<p>Orb is an unofficial build of the Pebble companion app by Core Devices, for phones without Google Play services. GrapheneOS is the primary target. It is Core's app with the Google and binary-only parts removed and as little else changed as possible.</p>

<p>Orb keeps the features of Core's app that don't need a Core account, for Pebble watches old and new.</p>

<p><b>Removed compared with the official app</b></p>
<ul>
<li>Firebase (accounts, crash reporting), Google sign-in, Google Play in-app updates and push messaging</li>
<li>Mixpanel analytics</li>
<li>The prebuilt Cactus speech engine</li>
<li>Support for Core's Index 01 ring, whose radio library is closed source. Orb has no plans to support the ring.</li>
<li>The Google Fit fallback (Health Connect is still used where available)</li>
<li>Classic PebbleKit, the original API for phone apps. Phone apps need PebbleKit 2.</li>
</ul>

<p>There is no Core account in Orb, so Core's cloud locker, cloud speech recognition and bug-report upload are unavailable. Orb imports your Rebble locker when signed in to Rebble. Bug reports can be saved and shared as a ZIP file.</p>

<p><b>Replaced</b></p>
<ul>
<li>System dictation needs Android 13 or newer and a recognizer that accepts recorded audio. System/offline dictation is not yet available on GrapheneOS. Rebble dictation works with a Rebble subscription; select a Rebble mode in speech settings.</li>
<li>PebbleOS updates for watches made by Core come from Core's public releases on GitHub. Each release is checked (published SHA-256, board, version and CRCs) before it is offered. Older Pebble watches update from Rebble.</li>
</ul>

<p>Orb blocks plain HTTP for itself, watchapps and settings pages and trusts system CAs only. PebbleKit 2 phone apps need a stored companion declaration and allowed access.</p>

<p>Android can install Orb next to the original Pebble app, Cobble, Gadgetbridge, Core's app or microPebble. Orb won't connect to a watch while one is installed unless "Ignore other Pebble apps" is on. Uninstall them first. Enabling that setting can make BLE connections unreliable and is not recommended.</p>
